# Vendored schema

`vcon_json_schema.json` is Appendix C of `draft-ietf-vcon-vcon-core-05`
(`$id` https://ietf.org/vcon/schemas/unsigned-vcon.json), copied verbatim.
It is the JSON Schema for the unsigned form of a vCon, syntax `"0.5.0"`.
It replaced the core-04 schema (syntax `"0.4.0"`, `recording_set` and
`party_history` Dialog parameters) when the adapter moved to core-05.
Replace it wholesale when the WG revises the schema; do not hand-edit it.
